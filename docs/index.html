What this lab is about

Most audio machine learning assumes clean clips, plenty of labels, and a big GPU. Perception in the real world gets none of those. A smoke-alarm detector has to run on a coin-sized board next to a running dishwasher. A home assistant cannot ask anyone to label ten thousand kitchen sounds. A robot that hears a crash has to work out whether it came from the doorway, the wall it echoed off, or the next room.

Our two modules each take on one of those gaps:

  1. Self-supervised audio learning via vision grounding. Let a frozen object detector watching a room supply pseudo-labels for the sounds it hears, and train an audio classifier from those, generation after generation.
  2. Audio-visual sound source localization with spatial physics. Combine microphone-array directions with a 3-D map of the room to tell visible sources from occluded ones and true sources from echoes.

The details, including the repository folders each module owns, are on Project ideas.

How long will this take?

Setup takes about 30 minutes. Each concept page takes 30 to 45 minutes to read properly with the demos and questions. Budget a week for the six core pages alongside your other commitments, then a few days for your module's pages.

What you need to know already

  • Python and NumPy: functions, arrays, slicing, and reading other people's code.
  • Basic linear algebra: vectors, dot products, matrix multiplication.
  • A little calculus and trigonometry: sines and cosines, logarithms. The pages explain everything else, including complex numbers where they appear.
  • Some PyTorch helps but is not required.
