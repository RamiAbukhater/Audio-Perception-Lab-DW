# `core/sync/`: Multimodal synchronization engine

**Module 2.** Captures time-aligned windows of ambient audio and RGB frames from a static indoor camera setup, stamped with one shared monotonic clock.

Read first:
- [09-cross-modal-pseudo-labels.html](../../docs/concepts/09-cross-modal-pseudo-labels.html#sync)

Recordings contain people. Get consent, keep raw audio and video out of the repository, and delete video once detections are extracted unless it is needed.
