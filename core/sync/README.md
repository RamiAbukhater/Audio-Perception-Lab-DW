# `core/sync/`: synchronised capture

**Pseudo-labelling loop.** Captures time-aligned microphone-array audio and RGB-D frames from a static indoor setup, stamped with one shared monotonic clock, and stores the array-to-camera calibration.

Read first:
- [08-cross-modal-pseudo-labels.html](../../docs/concepts/08-cross-modal-pseudo-labels.html#sync)
- [10-3d-geometry.html](../../docs/concepts/10-3d-geometry.html#frames)

Recordings contain people. Get consent, keep raw audio and video out of the repository, and delete video once detections are extracted unless it is needed.
